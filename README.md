# Chrome Extensions

このリポジトリには、Chrome拡張機能のプロジェクトが含まれています。

## 拡張機能一覧

| フォルダ | 説明 |
| --- | --- |
| `contents-to-markdown` | 現在開いている記事をMarkdown形式で取得します |
| `clipboard-to-obsidian` | クリップボードの内容をObsidianに転送します |
| `pomodoro-timer` | ポモドーロタイマー。独立ウインドウのウィジェットや、常に最前面のミニ表示でも使えます |

### pomodoro-timer の使い方

- ツールバーのアイコンからポップアップを開き、「開始」でタイマーを始めます。作業 25分 → 短い休憩 5分 を繰り返し、作業 4回ごとに長い休憩 15分になります（時間は「設定」で変更できます）
- フェーズが終わるとデスクトップ通知が出ます。次のフェーズは通知の「開始」ボタンかポップアップから始めます
- フェーズが終わると通知音も鳴ります。「設定」で音のオン・オフ、音の種類（チャイム／ベル／ビープ／やわらかい音）、音量を変えられます。「試しに鳴らす」で事前に確認できます
- 「ウィジェットで開く」を押すと、アドレスバーのない小さなウインドウで開きます。サブディスプレイなどに置いておくと、次回も同じ位置に開きます
- ウィジェットの「最前面に表示」を押すと、他のウインドウより上に浮かぶミニタイマーが開きます（ウィジェットのウインドウを閉じると一緒に閉じます）

## Chrome拡張機能の設定方法

### 1. 拡張機能をダウンロードまたはクローン

```bash
git clone https://github.com/hirokita117/chrome-extensions.git
cd chrome-extensions
```

### 2. Chromeで拡張機能を読み込む

1. Chromeブラウザを開く
2. アドレスバーに `chrome://extensions/` と入力してEnterキーを押す
   - または、メニュー（三点リーダー）→「拡張機能」→「拡張機能を管理」を選択
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリック
5. 読み込みたい拡張機能のフォルダを選択（例：`contents-to-markdown`）
6. 拡張機能が読み込まれ、ツールバーにアイコンが表示されます

### 3. 拡張機能の更新

拡張機能のコードを変更した場合：

1. `chrome://extensions/` ページを開く
2. 該当する拡張機能の「再読み込み」ボタン（🔄）をクリック

### 4. 拡張機能の削除

1. `chrome://extensions/` ページを開く
2. 削除したい拡張機能の「削除」ボタンをクリック
